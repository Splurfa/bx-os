# Antecedent Context Selection Guide for Teachers

## Overview

The antecedent context feature helps you identify what your class was doing when a behavioral incident occurred. This information is clinically important for understanding patterns and developing effective interventions.

## Why Context Matters

Understanding the **antecedent** (what happened before) helps:
- Identify environmental triggers for behaviors
- Develop targeted prevention strategies
- Create more effective behavior support plans
- Provide data for clinical analysis

## The 6 Context Categories

When creating a Behavior Support Request, you'll select from these six unified contexts:

### 1. Frontal Teaching (Lecture)
**When to select:** Teacher-led instruction with the whole class listening
- Direct instruction lessons
- Explaining new concepts
- Demonstrating procedures
- Whole-class presentations

### 2. Individual Quiet Classwork
**When to select:** Students working independently on assignments
- Silent reading
- Individual worksheets
- Test preparation
- Independent projects

### 3. Group/Partner Classwork  
**When to select:** Collaborative work with peers
- Small group projects
- Partner activities
- Team assignments
- Cooperative learning tasks

### 4. Group Discussion
**When to select:** Class discussions or sharing activities
- Whole-class discussions
- Student presentations
- Sharing thoughts/ideas
- Q&A sessions

### 5. Test/Quiz
**When to select:** Assessment or evaluation activities
- Formal tests
- Pop quizzes
- Performance assessments
- Evaluation activities

### 6. Transitions
**When to select:** Moving between activities, subjects, or locations
- Changing subjects
- Moving to different rooms
- Switching activities
- Packing up/unpacking

## Step-by-Step Process

### Step 1: Student Selection
1. Search for the student by name
2. Select the correct student
3. Click "Next" to continue

### Step 2: Context Selection (NEW)
1. Think about what the class was doing when the behavior occurred
2. Select ONE context that best describes the activity
3. Click "Next" to continue

### Step 3: Behavior Selection
1. Select ALL behaviors that apply (multiple selection allowed)
2. Choose from the six behavior categories
3. Click "Review" to continue

### Step 4: Review & Submit (NEW)
1. **Review your selections** displayed as colored chips
2. **Rate your current mood** using the slider (1 = Very Calm, 5 = Very Frustrated)
3. **Set urgency level:**
   - **Standard**: Regular processing
   - **Re-integration**: Priority return to class
   - **Urgent**: Immediate attention needed
4. **Add optional notes** for additional context
5. Click "Submit Behavior Support Request"

## Tips for Accurate Context Selection

### Be Specific
- Choose the context that was happening immediately before the behavior
- If transitioning between activities, select "Transitions"

### Think About Timing
- Consider what was happening in the 2-3 minutes before the incident
- The context should reflect the immediate trigger environment

### When in Doubt
- **Transitions** covers most between-activity situations
- **Frontal Teaching** includes any teacher-directed instruction
- **Individual Quiet Classwork** means students working alone

## Understanding Urgency Levels

### Standard
- Normal processing through the queue
- Student will be assigned to next available kiosk
- Typical for most behavioral incidents

### Re-integration
- Student should return to class as quickly as possible
- Prioritized processing
- Use when student needs to return for important activities

### Urgent
- Immediate attention required
- Highest priority in queue
- Use for safety concerns or severe incidents

## Teacher Mood Rating

The mood slider helps us understand:
- How incidents affect teacher wellbeing
- Patterns between context, behavior, and teacher stress
- System-wide teacher support needs

**1 = Very Calm** - Incident had minimal impact on you
**3 = Neutral** - Moderate impact, manageable
**5 = Very Frustrated** - Incident significantly affected you

## Frequently Asked Questions

**Q: What if multiple contexts were happening?**
A: Select the primary context that was most prominent when the behavior occurred.

**Q: What if I'm not sure about the exact context?**
A: Choose your best estimate. "Transitions" is often appropriate when unsure.

**Q: Can I change the context after submitting?**
A: Contact an administrator who can modify the record if needed.

**Q: How does this affect the student's reflection process?**
A: Students complete the same reflection process. Context data helps staff provide better support.

**Q: Is context selection required?**
A: Yes, selecting a context is now required for all new Behavior Support Requests.
